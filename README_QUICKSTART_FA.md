## پیش‌نیاز

- **Python 3.11 یا 3.12** (توصیه قوی)
- ویندوز ۱۰/۱۱ یا لینوکس

---

## اجرا در یک کلیک (ویندوز)

1. این پوشه را دانلود یا clone کنید.
2. روی فایل **`RUN_CRM.cmd`** دوبار کلیک کنید.
3. منتظر بمانید تا نصب و seed انجام شود.
4. مرورگر را باز کنید: **http://127.0.0.1:8000/**

## اجرا در لینوکس / مک

```bash
chmod +x RUN_CRM.sh
./RUN_CRM.sh
```

---

## اجرای دستی (اگر اسکریپت مشکل داشت)

```bash
# کپی تنظیمات
cp .env.example .env

# محیط مجازی
python3.12 -m venv .venv
source .venv/bin/activate   # لینوکس/مک
# یا در ویندوز: .venv\Scripts\activate

pip install -r requirements.txt
python -m scripts.seed
python -m scripts.verify_bootstrap_accounts
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
