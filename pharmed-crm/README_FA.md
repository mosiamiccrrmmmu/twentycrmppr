# PHARMED CRM 3.0.4

سامانه CRM فروش **فارمد پلیمر رایان**  
محیط کاملاً فارسی · حداکثر ۴ کاربر · اجرا روی سیستم محلی

## اجرا سریع (ویندوز)

1. وارد این پوشه شوید: `pharmed-crm`
2. روی فایل **`RUN_CRM.cmd`** دوبار کلیک کنید
3. مرورگر را باز کنید: **http://127.0.0.1:8000/**

## لینوکس / مک

```bash
cd pharmed-crm
chmod +x RUN_CRM.sh
./RUN_CRM.sh
```

## پیش‌نیاز

- Python **3.11 یا 3.12** (توصیه قوی)
